# Elective: Computer Programming (Java)

## Performance Standard

The learners:

* Perform procedures in setting up the Integrated Development Environment (IDE).
* Create algorithms, flowcharts, and pseudocode to plan and visualize their code.
* Create well-structured programs using Java operators, input and output classes, flow control structures, and arrays.
* Create efficient Java programs using flow control structures, arrays, and Object-Oriented Programming (OOP).
* Develop interactive and responsive applications using multithreading and graphical user interfaces (GUI).
* Incorporate market analysis to ensure solutions meet industry demands and customer needs.

---

## Content Standard

The learners demonstrate understanding of:

### Java Fundamentals

* Java programming concepts
* Basic structure and syntax
* Data types
* Variables
* Comments
* Algorithms
* Flowcharts
* Pseudocode

### Intermediate Java Programming

* Java Operators

# Budget of Work

## Week 1

### Learning Competencies

* Discuss the fundamental concepts of Java.
* Perform the steps in setting up the development environment.
* Discuss Java basic structures and syntax.
* Develop algorithms for designing a program or system.

### Suggested Activities

#### Java Concepts Quick Map

**Objective:** Learners identify key Java concepts.

**Activity:**

* Identify program structure, syntax, data types, variables, and comments.
* Create a concept map showing how these elements appear in a basic Java program.

---

#### Java Program Walk-Through

**Objective:** Explain the fundamental parts of a Java program.

**Activity:**

* Examine a sample Java program.
* Label and describe:

  * Class
  * Main Method
  * Variables
  * Comments

---

#### Java Tools Setup Check

**Objective:** Prepare the computer for Java programming.

**Activity:**

* Install the Java Development Kit (JDK).
* Open the IDE.
* Verify Java installation through version checking or IDE welcome screen.

---

#### First Project Test Run

**Objective:** Confirm that the development environment works.

**Activity:**

* Create a new Java project.
* Run a simple Java program.
* Verify successful execution.

---

#### Parts of a Java Program

**Objective:** Identify the basic parts of a Java program.

**Activity:**

* Label:

  * Class Name
  * Main Method
  * Variables
  * Comments
* Explain each part's purpose.

---

#### Syntax Spot-the-Error

**Objective:** Recognize correct and incorrect Java syntax.

**Activity:**

* Review code samples.
* Identify and correct:

  * Missing semicolons
  * Missing brackets
  * Incorrect keywords

---

#### Everyday Steps to Algorithm

**Objective:** Understand algorithms using familiar tasks.

**Activity:**

* Choose a simple daily activity (e.g., logging into a computer).
* Write step-by-step instructions as an algorithm.

---

#### Problem-to-Algorithm Challenge

**Objective:** Create an algorithm for a simple programming problem.

**Activity:**

* Example Problem: Display the sum of two numbers.
* Write the logical sequence of steps needed to solve it.

---

## Week 2

### Learning Competencies

* Develop flowcharts for designing a program or system.
* Develop pseudocodes for designing a program or system.

### Suggested Activities

#### From Steps to Flowchart

**Objective:** Convert algorithms into flowcharts.

**Activity:**

* Given a step-by-step solution, create a flowchart using:

  * Start
  * Process
  * Decision
  * End

---

#### Flowchart a Simple Problem

**Objective:** Design a flowchart for a simple problem.

**Activity:**

* Example Problem: Display the larger of two numbers.
* Draw the logical flow from start to end.

---

#### Algorithm to Pseudocode

**Objective:** Translate algorithms into pseudocode.

**Activity:**

* Example Problem: Display the sum of two numbers.
* Write pseudocode using proper sequence and keywords.

---

#### Pseudocode Fix-It Task

**Objective:** Improve pseudocode logic.

**Activity:**

* Review incomplete pseudocode.
* Correct and complete missing steps.

---

## Week 3

### Learning Competencies

* Apply operators in writing a Java program.
* Apply Java I/O classes to read and write data files in Java programs.

---

## Week 4

### Learning Competencies

* Apply Java Flow Control Structures in writing a Java program.
* Apply Java Arrays in writing a Java program.

---

## Week 5 and Beyond

### Learning Competencies

#### Algorithms and Arrays

* Apply sorting algorithms in a Java program that organizes customer transaction data stored in an array.

#### Object-Oriented Programming

* Discuss Object-Oriented Programming (OOP) Language in Java.
* Apply OOP principles in a Java program.

#### Exception Handling

* Apply exception handling in Java programs.

#### Collections Framework

* Apply Java Collections Framework in writing Java programs.

#### File Handling

* Apply the `java.io` package and Java file operations.
* Apply reading and writing classes in Java programs.

#### Multithreading

* Apply threads using:

  * Thread Class
  * Runnable Interface

#### Concurrency Utilities

* Create Java programs using:

  * CountDownLatch
  * CyclicBarrier
  * Semaphore

#### GUI Development

* Create simple GUI applications using:

  * JFrame
  * JLabel
  * JButton
  * JTextField
  * ActionListener

#### Layout Management

* Create user interfaces using:

  * FlowLayout
  * BorderLayout
  * GridLayout
* Effectively nest components using multiple JPanels.

#### Advanced GUI Applications

* Create interactive Java applications with advanced UI components.
* Handle complex user interactions.
* Improve user experience and responsiveness.

#### Business and Project Development

* Develop business plans for a system proposal.
* Create GUI application designs that solve real-world problems.

# Suggested Performance Tasks

## Individual Learning Activity

### My Java Workspace Setup

**Objective:**
Learners independently set up the Java IDE and prepare their workspace for coding.

**Task:**

* Install the Java Development Kit (JDK).
* Configure the IDE.
* Create and save a Java project.
* Verify readiness for coding.

---

## Group Activity

### Code Planning Team Lab

**Objective:**
Learners collaboratively plan a simple program before coding.

**Task:**

* Form small groups.
* Select a simple programming problem.
* Develop:

  * Algorithm
  * Flowchart
  * Pseudocode
* Present the program logic clearly.
